## 1. 一句话结论

**准生产安全与结构基线可用；默认 SQLite，PostgreSQL 为可选验证路径。** 历史安全 P1 仍在代码中成立；API 模块化与产品/流程/RAG 增强已落地。**Hybrid RAG**（本地 hash 向量 + 关键词）与 **双内置流程模板绑定** 为 as-built；完整可配置流程引擎、pgvector、外置队列仍属目标态。产品页主区为 **3 Tab**（产品/项目集/组合）；公司目标经页头 **「公司目标 / OKR」** 入口进入（非第 4 Tab）。文档协同已支持 **在线人数/presence 广播** 与最近保存时间展示。业务写审计会 **clear AI summary 进程缓存**。

**前端颗粒度 as-built**：业务 `pages/*` 为 **薄壳**（多为 7–8 行），域 UI 在 `features/<domain>/components/*`；公共 KPI 经 **MetricCard + MetricStrip**（grid/bar/hero）。设计 token（间距/KPI/表格/看板密度/主题安全表面色）已统一到 `styles/global.css` + glass compact 同步。

| 维度 | 状态 |
|------|------|
| 总体 | 本地可交付准生产安全基线 + 可选 PG 验证路径 |
| 验证 | `npm run test -w api`（默认 sqlite）；web typecheck/build；`npm run test:e2e -w web`（最小浏览器 smoke，CI 可启）；API `smoke-local` |
| as-built 栈 | Express + **SQLite 默认** / **PostgreSQL 可选** + JWT；React 19 + Vite + **HashRouter**；token **sessionStorage**（tab 作用域） |
| 前端结构 | **Page 壳 + features 域组件**；KPI：`MetricStrip`/`MetricCard` |

## 4. 验证命令（本地）

```bash
# API 单元/集成
npm run test -w api

# 前端类型与构建
npm run typecheck -w web
npm run build -w web

# API 冒烟（需 API 在 :4010）
node api/scripts/smoke-local.js

# 浏览器冒烟（需 API 在 :4010；Vite 可复用或由 Playwright 拉起）
# 含 smoke.spec + roles-flow（五角色登录/导航）
npm run test:e2e -w web

# API 多角色全流程写操作（需 API 在 :4010）
# 覆盖：登录权限、产品/项目/成员/迭代/WBS、需求与任务状态机、
# 用例执行/缺陷、构建发布审批、日报工时、容量/战略/治理、AI 读、拒绝用例
npm run smoke:roles -w api
# 浏览器：smoke + roles-flow + full-ui-flow（全导航与关键交互）
npm run test:e2e -w web
```
