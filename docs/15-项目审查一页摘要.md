## 1. 一句话结论

**内部试用 RC 可用；默认 SQLite，PostgreSQL 为可选验证路径。** 2026-07-23 完成 RC 安全/稳定性整改（源码路径 allowlist、审计/AI 可见性隔离、Express async 包装、useAsync 显式 cacheKey、会话竞态、上传/DOCX/容量窗口）。API 模块化与产品/流程/RAG 增强已落地。**Hybrid RAG**（本地 hash 向量 + 关键词）与 **双内置流程模板绑定** 为 as-built；完整可配置流程引擎、pgvector、外置队列仍属目标态。产品页仅 **3 Tab**（产品/项目集/组合）；公司目标 API 保留但页面入口已移除。文档协同已支持 **在线人数/presence 广播** 与最近保存时间展示。业务写审计会 **clear AI summary 进程缓存**。

**前端颗粒度 as-built**：业务 `pages/*` 为 **薄壳**（多为 7–8 行），域 UI 在 `features/<domain>/components/*`；公共 KPI 经 **MetricCard + MetricStrip**（grid/bar/hero）。默认 UI 已切换为 `scholar/light/standard`、15px 的专业工作台，生产视觉覆盖集中在 `styles/enterprise-ui.css`；极光玻璃等主题继续作为用户可选皮肤。主题设置的字号、高对比、环境光、密度、导航、持久化与恢复默认均有浏览器回归。

| 维度 | 状态 |

## 4. 验证命令（本地）

```bash
# 生产依赖审计（CI 门禁；仅 --omit=dev）
npm run audit:prod

# ESLint（API + Web，warning budget = 0）
npm run lint

# 启动环境预检 / SQLite 备份恢复演练 / 优雅停机演练 / 生产冒烟
npm run preflight:env
# 启动时：密钥/PORT/危险 opt-in fail-closed；SQLite 目录可写；init 后 schema_migrations 与 migrations/ 对齐
# 备份命令：npm run backup:sqlite -- --database path/to/app.db --out path/to/backups --label nightly
# 恢复命令：npm run restore:sqlite -- --from path/to/backup-dir --database path/to/app.db --force
npm run preflight:database -w api
# 已有库：integrity + 引用/JSON + 迁移 ledger + 目录可写
npm run drill:sqlite-backup
# 临时库：备份 → 改数 → 恢复 → 校验 marker 与 preflight
npm run drill:graceful-shutdown
# 临时 API 进程共享 shutdown()（Windows 走 HTTP）；退出后 integrity_check + 可再打开写入 + 迁移正常
npm run smoke:prod
# 临时生产进程：SERVE_WEB + readiness + index.html + CSP 无 upgrade-insecure-requests / 无 HSTS
# 单机试用：见 docs/16-sqlite-trial-deploy.md → npm run start:prod


# API 单元/集成
npm run test -w api

# 前端类型 + Vitest
npm run test -w web
npm run build -w web

# 一次性 SQLite RC E2E（默认）
# 浏览器：smoke + roles-flow + rc-security-flow（登录过期/跨账号/产品三 Tab/成员与移交）

npm run test:rc-e2e
# 仅浏览器、跳过 full-ui：node scripts/rc-e2e.js --skip-api-roles --skip-full-ui

# RC 全量门禁（audit+lint+test+build+preflight+drill+e2e）
npm run check:rc

# API 冒烟（需 API 在 :4010）
node api/scripts/smoke-local.js

# 浏览器冒烟（需 API 在 :4010；Vite 可复用或由 Playwright 拉起）
```
