# UI 交互设计方案

> **适用阶段**：全阶段。导航、状态标签、页面按阶段标注归属，阶段一一级导航收敛为 6 项（详见 [00 §1](./00-数据字典与术语统一.md)）。状态枚举以 00 为准，本文示例仅为样式参考。

## 1. 设计方向

整体风格参考 Codex 类工作台：简洁、克制、信息密度适中，以任务、状态、上下文和行动入口为核心。不做营销式大色块、不做复杂装饰、不使用强烈渐变和过度拟物。

关键词：

- 简洁
- 专业
- 安静
- 高效
- 清晰
- 可追踪

视觉目标：

- 用户进入页面后能立即判断当前要处理什么。
- 重要状态和风险清楚可见，但不制造视觉噪音。
- AI 能力像侧边助手一样嵌入流程，而不是抢占主界面。
- 页面整体类似开发工具、协作平台和管理控制台的结合。

## 2. 视觉风格

### 2.1 色彩

推荐使用低饱和中性色为主，少量状态色辅助。

基础色：

- 页面背景：`#F7F7F5` 或 `#FAFAF8`
- 主内容背景：`#FFFFFF`
- 主要文字：`#1F2328`
- 次级文字：`#656D76`
- 边框线：`#D8DEE4`
- 分隔线：`#EAEEF2`

品牌主色：

- 深灰黑：`#24292F`
- 可用于主按钮、选中态、重点图标。

状态色：

- 成功：`#2DA44E`
- 警告：`#BF8700`
- 风险：`#CF222E`
- 信息：`#0969DA`
- 阻塞：`#8250DF`

使用规则：

- 大面积区域不要使用高饱和颜色。
- 状态色只用于标签、图标、细线、徽标和关键数字。
- 图表颜色保持低饱和，避免看起来像营销仪表盘。

### 2.2 字体

推荐字体：

- 中文：`PingFang SC`、`Microsoft YaHei`
- 英文和数字：`ui-sans-serif`、`Segoe UI`
- 代码和编号：`ui-monospace`、`SFMono-Regular`、`Consolas`

字号建议：

- 页面标题：20px
- 区块标题：16px
- 正文：14px
- 辅助说明：12px
- 表格正文：13px

排版规则：

- 不使用超大标题。
- 不使用负字距。
- 行高保持 1.45 到 1.6。
- 数字、状态和编号可使用等宽字体增强扫描效率。

### 2.3 圆角与阴影

推荐：

- 卡片圆角：6px
- 按钮圆角：6px
- 输入框圆角：6px
- 弹窗圆角：8px

阴影规则：

- 默认不使用重阴影。
- 卡片主要依靠边框和浅背景区分。
- 弹窗、下拉菜单、浮层可使用轻阴影。

## 3. 布局结构

采用固定左侧导航 + 顶部工具栏 + 主工作区 + AI 侧栏的结构。

```text
+-------------------------------------------------------------+
| 顶部栏：全局搜索 / 新建 / 通知 / AI / 用户                  |
+------------+--------------------------------+---------------+
| 左侧导航   | 主工作区                       | AI 侧栏        |
|            | 列表 / 看板 / 详情 / 流程图     | 总结 / 风险    |
|            |                                | 建议 / 证据    |
+------------+--------------------------------+---------------+
```

布局规则：

- 左侧导航宽度建议 220px，可折叠为图标模式。
- 顶部栏高度建议 52px。
- 主工作区保持 24px 内边距。
- AI 侧栏宽度建议 360px，可收起。
- 页面不使用大面积装饰背景。

## 4. 导航设计

完整一级导航（括号内为阶段归属）：

- 个人工作台（阶段一，默认页）包含：任务列表、指标卡、**工作日志提交入口**与日志列表
- 项目（阶段一，含 WBS/Kanban/Sprint；项目集 Program 视图属阶段三）
- 需求管理（阶段一）
- 测试管理（阶段一）
- 文档中心（阶段一上传/列表，AI 文档分析闭环属阶段二）
- 系统设置（阶段一基础，含个人设置与简化角色）
- 项目集（阶段三）
- 产品集（阶段三）
- 开发流程（阶段三，流程引擎）
- 组织管理（阶段三细粒度；阶段一仅只读组织视图）
- AI 分析（阶段二）
- 报表（阶段二）

> **阶段一一级导航收敛为 6 项**：工作台 / 项目 / 需求管理 / 测试管理 / 文档中心 / 系统设置。其余菜单在对应阶段开放。

导航风格：

- 左侧竖向导航。
- 当前菜单使用浅灰背景 + 左侧细线强调。
- 图标使用线性风格。
- 菜单文字保持短，不使用宣传式描述。

## 5. 组件规范

### 5.1 按钮

按钮类型：

- 主按钮：深灰黑背景，用于提交、确认、创建。
- 次按钮：白底边框，用于取消、筛选、导出。
- 文本按钮：用于低权重操作。
- 危险按钮：红色，仅用于删除、关闭、驳回等动作。

按钮规则：

- 按钮文案短，例如“新建任务”“确认分析”“导出”。
- 常用工具按钮可使用图标。
- 同一区域主按钮不超过一个。

### 5.2 标签

状态标签应简洁，不做胶囊大色块。

示例（英文状态值为字段存储值，UI 显示可本地化展示可读文本；完整枚举见 [00 §2](./00-数据字典与术语统一.md)）：

- `in_progress` → 进行中
- `blocked` → 阻塞
- `acceptance` → 待验收
- `done` → 已完成

标签样式：

- 浅底色 + 状态色文字。
- 高度 22px。
- 字号 12px。

### 5.3 表格

表格是项目集、需求、测试、文档的主视图。

规则：

- 表头固定。
- 支持列筛选、排序、密度切换。
- 行高默认 40px。
- 重要状态用标签，不用整行高亮。
- 行点击打开右侧详情抽屉，减少页面跳转。

### 5.4 卡片

卡片只用于项目、任务、指标等独立对象，不做层层嵌套。

样式：

- 白底
- 1px 边框
- 6px 圆角
- 无重阴影
- 标题、状态、负责人、时间、风险清晰排列

### 5.5 AI 侧栏

AI 侧栏是平台的固定能力入口。

内容结构：

- 当前上下文摘要
- 风险识别
- 建议动作
- 证据引用
- 可写入项
- 人工确认按钮

交互规则：

- AI 结果默认不直接写入业务数据。
- 每条建议都应有“确认”“编辑”“忽略”。
- 证据引用可以跳转到原文、日志、需求或任务。

## 6. 个人工作台

个人工作台使用“指标条 + 任务列表 + 当前详情 + AI 总结”的布局。

页面结构：

- 顶部：今日任务、已完成、逾期、阻塞、待审批、本周完成度。
- 左侧：任务队列，按今日、逾期、阻塞、待验收分组。
- 中间：当前任务详情、流程位置、关联需求、验收标准。
- 右侧：AI 总结、风险、下一步建议、日报分析。

交互：

- 点击任务后在中间区域展示详情。
- 更新任务状态后即时刷新流程位置。
- 提交日报后在 AI 侧栏生成分析结果。
- AI 识别出的需求完成度变化需人工确认。

## 7. 项目集

项目集默认使用表格视图，辅以看板和甘特图。

视图：

- 表格：适合管理层快速筛选。
- 看板：按项目状态分组。
- 甘特图：查看里程碑。
- 健康度：查看风险和质量。

项目状态：

- 立项中
- 规划中
- 需求中
- 设计中
- 开发中
- 测试中
- 验收中
- 发布中
- 运维中
- 暂停
- 关闭
- 归档

项目列表字段：

- 项目名称
- 状态
- 健康度
- 负责人
- 进度
- 当前里程碑
- 风险数
- 逾期任务
- 更新时间

## 8. 产品集

产品集采用“产品树 + 路线图 + 需求池”的布局。

页面结构：

- 左侧：产品线、产品、模块树。
- 中间：版本路线图。
- 右侧：需求池和 AI 规划建议。

交互：

- 需求可从需求池加入版本。
- 版本可查看关联项目和发布范围。
- AI 可基于需求价值、风险和资源给出优先级建议。

## 9. 需求、测试、文档

需求管理：

- 默认表格视图。
- 详情页展示需求描述、验收标准、任务、测试、文档、日志证据。
- 完成度以进度条 + 维度分数展示。

测试管理：

- 使用页签组织：计划、用例、执行、缺陷、报告。
- 缺陷状态使用清晰标签，不用大面积红色。

文档中心：

- 左侧分类树。
- 中间文档列表。
- 右侧预览和 AI 分析。
- 文档 AI 分析结果必须展示引用证据。

## 10. 管理驾驶舱

管理驾驶舱保持克制，不做炫技大屏。

核心区域：

- 顶部关键指标。
- 中部项目健康度和风险列表。
- 下方产品、需求、测试、人员负载趋势。

图表风格：

- 浅色背景。
- 细网格线。
- 低饱和配色。
- 图例简洁。
- 点击图表可下钻到项目、产品或需求列表。

## 11. 移动端

移动端只承载高频轻操作。

支持：

- 查看今日任务
- 更新任务状态
- 提交日报
- 查看通知
- 审批流程节点
- 查看 AI 总结

不建议在移动端承载复杂甘特图、流程模板配置和大批量数据维护。

## 12. 页面示例风格

个人工作台示意：

```text
个人工作台

[今日任务 12] [已完成 5] [逾期 2] [阻塞 1] [待审批 3]

+------------------+-------------------------------+-------------------+
| 任务队列         | 当前任务                      | AI 总结            |
| 今日             | 任务标题                      | 完成事项           |
| 逾期             | 状态 / 负责人 / 截止时间       | 风险               |
| 阻塞             | 流程位置                      | 下一步建议         |
| 待验收           | 关联需求 / 验收标准            | 证据引用           |
+------------------+-------------------------------+-------------------+
```

项目集示意：

```text
项目集

[全部] [高风险] [我负责] [本周到期]       [新建项目]

项目名称        状态      健康度   负责人   进度   风险   更新时间
研发平台一期    开发中    82       张三     64%    3      今天
客户交付项目A   测试中    76       李四     81%    5      昨天
```
