## 1. 文档目的

本文档用于指导平台前后端开发、Mock、联调和验收。范围按三阶段交付（见 [00 §1](./00-数据字典与术语统一.md)）：

- **阶段一**：个人工作闭环、项目执行（WBS/Sprint/Kanban）、需求、测试缺陷、基础文档与组织。
- **阶段二**：AI 文档闭环（文档分析 Job / RAG / 确认写入）、AI 日志深度分析、真实报表。
- **阶段三**：Program/Portfolio/Product 战略层、流程引擎、细粒度权限、标书分析。

> **实现现状提示**：原计划阶段一收敛约 20 个接口，但当前代码已**超前实现约 70 个接口**，覆盖全部资源域（含本应属阶段三的 programs/portfolios/products 管理端点、阶段二的 AI 摘要等）。下文 §1.1 保留原"阶段一收敛清单"作为 MVP 范围参考，§1.2 给出实际全量清单。

## 2. 通用接口规范

### 2.1 请求规范

- API 前缀：`/api`
- 鉴权：`Authorization: Bearer <token>`
- 内容类型：`application/json`
- 时间格式：ISO 8601，例如 `2026-06-23T10:30:00+08:00`
- ID 格式：后端可使用 UUID，前端不依赖 ID 编码规则

### 2.2 成功响应（统一信封）

所有成功响应统一为 `{ data, meta }` 双层信封（无 `success` 字段）：

```json
{
  "data": { },
  "meta": { "generatedAt": "2026-06-24T08:00:00Z" }
}
```

- `meta.generatedAt` 恒有；分页等场景可携带额外 meta 字段。
- 前端通过 `services/apiClient.ts` 解包 `.data` 取业务对象；业务请求函数按领域放在 `web/src/features/<domain>/api.ts`。

### 2.3 分页响应（有条件触发）

列表端点**仅当 query 同时携带 `page` 与 `pageSize` 时**返回分页结构，置于 `data` 内（`pageSize` 上限 200）；否则 `data` 直接为数组：

```json
{
  "data": { "items": [], "page": 1, "pageSize": 20, "total": 0 },
  "meta": { "generatedAt": "2026-06-24T08:00:00Z" }
}
```

> 前端当前列表调用**未传分页参数**，按纯数组消费（见 [10 §3](./10-实现状态与差异清单.md)）。

### 2.4 错误响应

```json
{
  "errorCode": "PERMISSION_DENIED",
  "message": "无权访问该资源",
  "traceId": "1f0c…uuid"
}
```

错误响应**不带 `data`/信封**，结构与成功响应不对称。`traceId` 为 UUID。

常见错误码（实际使用值）：

| 错误码 | HTTP | 场景 |
| --- | --- | --- |
| `UNAUTHENTICATED` | 401 | 缺少/无效 token |
| `INVALID_CREDENTIALS` | 401 | 登录账号或密码错误 |
| `PERMISSION_DENIED` | 403 | 权限不足 |
| `VALIDATION_FAILED` | 400 | 请求参数不合法 |
| `RESOURCE_NOT_FOUND` | 404 | 对象不存在 / 未匹配路由 |
| `RATE_LIMITED` | 429 | 触发限流（全局 600/15min，登录 20/15min） |
| `INTERNAL_SERVER_ERROR` | 500 | 服务器内部错误（生产隐藏细节） |

> 目标态曾规划 `STATE_NOT_ALLOWED`、`AI_JOB_FAILED`、`AI_MODEL_TIMEOUT` 等错误码，当前代码未使用。
