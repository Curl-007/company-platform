# 接口清单与开发任务拆分

> **适用阶段**：全阶段。接口命名、状态枚举、错误结构、分页结构以 [00 数据字典](./00-数据字典与术语统一.md) 为准。

## 1. 文档目的

本文档用于指导平台前后端开发、Mock、联调和验收。范围按三阶段交付（见 [00 §1](./00-数据字典与术语统一.md)）：

- **阶段一**：个人工作闭环、项目执行（WBS/Sprint/Kanban）、需求、测试缺陷、基础文档与组织。
- **阶段二**：AI 文档闭环（文档分析 Job / RAG / 确认写入）、AI 日志深度分析、真实报表。
- **阶段三**：Program/Portfolio/Product 战略层、流程引擎、细粒度权限、标书分析。

### 1.1 阶段一接口清单（收敛后，约 20 余个）

历史"一期"清单含 50+ 接口，重规划后阶段一只保留下列真正需要的端点；Program/Portfolio/Product、AI 文档分析、RAG、标书等接口下移阶段二/三。

| 域 | 端点 |
| --- | --- |
| 鉴权/组织 | `POST /api/auth/login`、`GET /api/auth/me`、`GET /api/org`（只读） |
| 个人工作 | `GET /api/dashboard/personal`、`GET /api/tasks`、`GET /api/tasks/{id}`、`PATCH /api/tasks/{id}/status`、`GET/POST /api/work-logs`、`POST /api/work-logs/analyze`（规则版） |
| 项目执行 | `GET/POST /api/projects`、`GET /api/projects/{id}`、`PATCH /api/projects/{id}/status`、`GET /api/projects/{id}/wbs`、`POST /api/projects/{id}/wbs/tasks` |
| 迭代看板 | `GET/POST /api/projects/{id}/sprints`、`GET /api/projects/{id}/kanban`、`PATCH /api/tasks/{id}/kanban-position` |
| 需求 | `GET/POST /api/requirements`、`PATCH /api/requirements/{id}`、`PATCH /api/requirements/{id}/status`、`GET /api/requirements/{id}/completion-score` |
| 测试缺陷 | `GET/POST /api/test-cases`、`POST /api/test-runs`、`POST /api/defects`、`PATCH /api/defects/{id}/status` |
| 文档（基础） | `GET/POST /api/documents`、`GET /api/documents/{id}` |

> 下文 §3 给出**完整目标态**接口（含各阶段），每组标注阶段归属。

## 2. 通用接口规范

### 2.1 请求规范

- API 前缀：`/api`
- 鉴权：`Authorization: Bearer <token>`
- 内容类型：`application/json`
- 时间格式：ISO 8601，例如 `2026-06-23T10:30:00+08:00`
- ID 格式：后端可使用 UUID，前端不依赖 ID 编码规则

### 2.2 分页响应

```json
{
  "items": [],
  "page": 1,
  "pageSize": 20,
  "total": 0
}
```

### 2.3 错误响应

```json
{
  "errorCode": "PERMISSION_DENIED",
  "message": "无权访问该资源",
  "traceId": "trace_202606230001"
}
```

常见错误码：

| 错误码 | 场景 |
| --- | --- |
| `VALIDATION_FAILED` | 请求参数不合法 |
| `PERMISSION_DENIED` | 权限不足 |
| `RESOURCE_NOT_FOUND` | 对象不存在 |
| `STATE_NOT_ALLOWED` | 当前状态不允许操作 |
| `AI_JOB_FAILED` | AI Job 执行失败 |
| `AI_MODEL_TIMEOUT` | 模型调用超时 |

## 4. 前端开发任务拆分

| 编号 | 任务 | 阶段 | 主要页面/组件 | 依赖接口 |
| --- | --- | --- | --- | --- |
| FE-01 | 应用骨架与权限路由 | 一 | 登录后布局、左侧导航(6 项)、顶部栏 | Auth、User、Menu |
| FE-02 | 个人工作台 + 工作日志 | 一 | 指标卡、任务队列、工作日志输入与列表、日志分析结果 | Dashboard、Task、Work Log |
| FE-03 | Project（含 WBS 树） | 一 | 项目列表、项目详情、状态流转、WBS 树 | Project、WBS |
| FE-04 | Scrum/Kanban | 一 | Sprint Backlog、Kanban 看板、任务拖拽 | Sprint、Task、Kanban |
| FE-05 | Requirement | 一 | 需求列表、需求详情、完成度展示 | Requirement |
| FE-06 | 测试与缺陷 | 一 | 用例列表、测试执行、缺陷详情 | Test Case、Test Run、Defect |
| FE-07 | 文档中心（基础） | 一 | 文档列表、上传、预览 | Document |
| FE-08 | AI 分析中心 | 二 | Job 进度、结构化结果、证据引用、确认写入 | AI Job、RAG |
| FE-09 | 报表驾驶舱 | 二 | 项目健康度、个人趋势 | Report |
| FE-10 | Program/Portfolio 战略层 | 三 | 项目集/产品集视图、版本路线图 | Program、Portfolio |

前端交付要求：

- 每个列表页支持搜索、筛选、分页、空状态和错误状态。
- 每个状态变更操作显示确认反馈，失败时展示后端错误信息。
- AI 结果必须展示证据引用和人工确认入口。
- Mock 数据字段应与本接口文档一致，避免联调时大面积改字段。

- 文档密级影响下载、预览、AI 分析和 RAG 检索范围。

## 7. 里程碑（按阶段）
