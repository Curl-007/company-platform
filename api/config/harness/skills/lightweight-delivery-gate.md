# 轻量交付准入判断

逐条评估以下四个准入条件。全部满足才可走轻量交付；任一不满足即建议固定交付。

## 准入条件

1. **需求规模**：关联工作项（需求拆出的任务/用例合计）不超过 8 个。
   超过 → 不满足。
2. **外部合规依赖**：不涉及外部合规、审计或跨公司合同约束。
   涉及 → 不满足（此类交付必须走固定交付留痕）。
3. **人力承接**：单人可承接完成（开发 + 测试可由同一人或极小范围协作）。
   需要多角色交接 → 不满足。
4. **里程碑数量**：里程碑不超过 2 个（通常为交付 + 验收）。
   超过 → 不满足。

## 输出要求

- **准入结论**：满足 / 不满足。
- **理由**：逐条列出四个条件的判定与依据数据（工作项计数、里程碑清单、
  成员分工等），不满足的条目说明差距。
- **建议模板**：固定交付 或 轻量交付。
  - 四条全满足 → 轻量交付。
  - 任一条不满足 → 固定交付，并指出若想走轻量需要先收敛哪一项。
- 结论必须由数据推导：无法确认工作项数量或里程碑时，先说明缺失的数据，
  不得直接判满足。
